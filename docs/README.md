# Project Documentation

This folder contains the main written documentation for the senior thesis project.

## Folder Structure

### `project_proposal/`
Contains the submitted project proposal, including the research question, project scope, planned methods, and original 10-week project timeline.

### `literature_review/`
Contains the completed literature review used to support the project methodology, weather-feature definitions, model-development strategy, and interpretation of results.

### `weekly_status/`
Contains weekly status submissions documenting planned work, completed tasks, progress compared with the original timeline, upcoming work, and supporting evidence.

## Related Repository Sections

Additional project materials are available elsewhere in the repository:

- `scripts/` — R scripts used for data auditing, feature engineering, modeling, and evaluation
- `methodology/` — Methodology Decision Table and feature-definition documentation
- `evidence/` — selected figures and summary outputs supporting weekly progress reports
