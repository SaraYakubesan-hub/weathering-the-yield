# Methodology

This folder contains the working methodology documentation for the senior thesis project.

## Methodology Decision Table

`Methodology_Decision_Table.xlsx` serves as the main record of analytical decisions made during project development.

It documents decisions related to:

- study outcome, period, and geography
- historical baseline structure
- conventional and extreme-weather predictors
- growing-season time windows
- rolling-origin validation
- final 2022–2025 holdout evaluation
- performance metrics
- preprocessing and leakage safeguards
- model-comparison rules
- reproducibility

The workbook also contains a `Feature Definitions` sheet that records the final weather windows, conventional weather predictors, extreme-weather indicators, excluded alternatives, literature basis, and implementation notes.

## Use

This file is updated as methodology decisions are finalized or clarified during development. Major changes are intended to be documented before the final holdout period is used for evaluation.
